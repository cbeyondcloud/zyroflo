# Getting help

## Using Zyroflo

- **Read first:** the [README](README.md) (install, the lifecycle, the gates, the ledger),
  [`sdlc/LIFECYCLE.md`](sdlc/LIFECYCLE.md) (the phases and gate regimes) and
  [`RUNNER_CONTRACT.md`](RUNNER_CONTRACT.md) (bringing another AI tool or model).
- **A bug** - the harness does something other than what it documents: open an issue with the
  bug-report template. The command, its exit code and output, and the smallest repository shape
  that shows it are what get it fixed.
- **An idea** - open an issue with the feature-request template. Every change here starts as a
  row in [`SDLC-harness-backlog.md`](SDLC-harness-backlog.md); a good request becomes one.
- **A security vulnerability** - never a public issue. Follow [`SECURITY.md`](SECURITY.md).

Support here is community, best effort: the maintainers read every issue, with no response-time
promise.
